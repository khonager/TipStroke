# Roadmap

## NOW — drawing vertical slice

Validate low-latency stylus authoring, pressure, three brushes, transparent erasing, sparse per-layer tile commits, camera gestures, bounded undo/redo, non-destructive image layers, layer opacity/order/visibility, and reference-device diagnostics.

## NEXT

1. Crash-safe autosave and the versioned native project package, plus PNG export.
2. Gallery and document creation.
3. Layer renaming, transform handles, blend modes, and tiled image pyramids for extremely large sources.
4. Transform and selection.
5. Brush duplication/customization and brush assets.
6. Animation model, cels, timeline, playback, onion skin, and initial export.
7. Real vector layers and the icon/logo workflow with SVG import/export.

## LATER

Advanced brushes/effects, masks and blend modes, richer vector editing, advanced animation/export, Linux, iPad/iOS native input/rendering, and optional Windows/macOS clients.
